# LUMEN · Demo

Demo estática de LUMEN: seguimiento legislativo y asistente de derecho laboral de Guatemala.
Todos los datos son ficticios. Sin backend. No es asesoría legal.

## Correr local
    npm install
    npm run dev

## Publicar en GitHub Pages
1. En `vite.config.js` cambia `base` por `'/NOMBRE-DE-TU-REPO/'`.
2. Sube el proyecto a GitHub.
3. Ejecuta `npm run deploy`.
4. En el repo: Settings > Pages > rama `gh-pages`, carpeta `/ (root)`.
5. Abre `https://vennusamery.github.io/NOMBRE-DE-TU-REPO/`.
